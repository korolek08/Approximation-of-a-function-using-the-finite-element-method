Программа строит MSR-матрицу, решает систему указанным итерационным методом на базе параллельных вычислений. Для визуализации результатов подключается библиотека Qt5. Условия задач (LinearSystemsIterQt-4.pdf) составлены Кириллом Юрьевичем Богачевым, профессором кафедры вычислительной математики механико-математического факультета МГУ.
